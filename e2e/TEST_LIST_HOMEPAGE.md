# E2E 테스트 목록 — 메인 페이지

- 데스크톱: 1280×800px
- 태블릿: 768×1024px

| H-4 | 내부 문서 링크는 최신 안정 버전으로 연결 | 메인 페이지·푸터·내비게이션의 `/docs/` 링크가 모두 최신 안정 버전 경로와 일치 |

| FD-1 | 프레임워크 상세 헤딩 | 레벨 3 헤딩에 "에이전트를 위한 프레임워크" 문구 포함 |
